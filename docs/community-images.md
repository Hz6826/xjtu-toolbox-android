# 社区插入图片

发帖、回复、编辑正文的工具栏都有「图片」。可直接插入 HTTPS 图片地址，并在预览页查看。

Android 和桌面还可以选本机图片。首次使用「图片上传设置」时，准备一个自己的公开 GitHub 图片仓库，并填写只授权该仓库 Contents 读写权限的细粒度访问令牌。不要使用源码仓库。令牌与社区登录分开，只在本机安全存储中按 GitHub 用户保存，默认数据导出不包含它，可随时在该设置中清除。

选图后应用重新编码，去除 EXIF 等元数据，最长边缩至不超过 2048 像素、输出不超过 2 MB。支持 PNG/JPEG；输入文件不超过 20 MB、4000 万像素。Android 会按 EXIF 方向旋转后编码。桌面只读取 PNG/JPEG。

应用会再次提示公开仓库和图片大小，点击「公开上传并插入」后才写入。上传后使用固定提交的 raw URL 插入 Markdown。上传独立于发帖，放弃草稿或删除帖子不会删除图片仓库中的文件；如需移除，应到自己的仓库清理文件和相关历史。上传失败保留正文，不会自动重试写入。

GitHub 没有公开的 Discussion 附件上传接口，此功能使用官方仓库 Contents API，不模拟网页登录或借用项目维护者凭据。Web 端目前支持图片链接插入，本机上传需要 Android 或桌面。

接口参考：https://docs.github.com/en/rest/repos/contents#create-or-update-file-contents
